MatrixSite backend deployment checklist

1. Copy the backend app files to /srv/mysite-backend on the Linux server,
   including the my-site/server/ folder from the repo.
2. cp my-site.env.example my-site.env  and fill in:
     - MYSQL_* (host, user, password, database)
     - JWT_SECRET, ADMIN_USERS, CORS_ORIGINS, FRONTEND_ORIGIN
     - AUTHME_SHIM_SECRET   (value from plugins/MatrixStats/config.yml)
     - AUTHME_SHIM_CA_PATH  (path to a copy of auth-shim-cert.pem)
3. Confirm MariaDB is running locally; the database and credentials match.
4. Make start.sh executable:  chmod +x start.sh
5. Install / enable systemd unit:
     cp systemd/mysite-backend.service /etc/systemd/system/
     systemctl daemon-reload
     systemctl enable --now mysite-backend
6. (Optional) Drop nginx/backend.conf.example into your nginx site config
   and reload nginx.
7. Build the frontend separately (npm run build inside my-site/) and point
   it at the backend with VITE_API_BASE.
8. Make sure the Minecraft server has the MatrixStats plugin installed
   alongside AuthMe, so the shim endpoints are reachable.
9. Restart the backend service after any my-site.env changes:
     systemctl restart mysite-backend
